# PromptPilot v0.6.0

Большое обновление после v0.5.1: развитие workflow, управление очередями и
восстановление исполнения после сбоев. Сохранены Web UI, Telegram-бот и работа
с Claude Code, Codex, Qwen, Cursor Agent и настраиваемыми CLI-провайдерами.

## Основные изменения

- **Расписание и очереди.** Исправлены управление сериями, восстановление
  прерванных повторов, отображение последних запусков и сохранение явных
  настроек задачи. В диагностике различаются ожидание CI, квоты API, ручного
  решения и отсутствие подходящей работы. Парковка одной цели позволяет
  продолжать обработку других допустимых задач.
- **Workflow.** Развиты утверждаемые планы исполнения, вопросы оператору,
  одноразовые ответы, объявленные проверки этапов и последовательная
  публикация проверенного Git-результата. Checkpoint и восстановление
  привязаны к фактическим входам и текущей попытке.
- **Надёжность worker.** Усилены владение дочерними процессами, отмена,
  восстановление и защита от повторного исполнения. В управляемых workflow
  и технических передачах неизвестный исход запуска или публикации сохраняет
  барьер для инженерной сверки; истечение времени само по себе не разрешает
  повторить действие.
- **Web UI и Telegram.** Улучшены карточки, статусы стадий и управление
  расписанием; добавлены общее окно настроек и светлая/системная тема.
  Исправлены передача длинных промптов Claude через stdin, обработка итогов
  Codex/herdr и чтение конфигураций UTF-8. Усилены проверки Host/Origin API.
- **Входящие обращения.** В исходниках доработаны сценарии приёма писем и
  вложений (`scripts/inbox`), устранение дубликатов и доставка результатов
  через настроенные каналы. Эти внешние сценарии настраиваются отдельно.
- **GitHub-конвейер.** Развиты проверяемое обновление обычных отставших веток,
  раздельная диагностика технических и продуктовых блокеров, контроль точного
  HEAD и единственного исполнителя. Успешное ревью, `ship`, обязательные CI и
  последовательность слияния остаются отдельными условиями.

## Экспериментальная техническая передача

Протокол `review-routing-v1` позволяет передавать независимо воспроизведённый
технический блокер одному исполнителю с конечным бюджетом доработок и новым
независимым ревью результата. Продуктовая развилка, исключение безопасности,
нехватка данных и ошибка инструмента не становятся автоматическим FIX.

Этот режим **выключен по умолчанию** и требует явной настройки и согласованной
пары PromptPilot, checker и канонических процедур. Внешние ветки не получают
автоматическое исполнение по одному назначению. Положительное типизированное
ревью не переносится через обычный legacy base-sync: для отставшей ветки
нужны актуальная база и новое полное ревью. Рабочий пилот продолжается;
сокращение обращений к владельцу или времени поставки этим релизом не доказано.

Подробнее: [контракт](https://github.com/ivanarama/PromptPilot/blob/v0.6.0/docs/review-routing-v1.md),
[управляемый FIX](https://github.com/ivanarama/PromptPilot/blob/v0.6.0/docs/technical-fix-worker.md),
[диагностика](https://github.com/ivanarama/PromptPilot/blob/v0.6.0/docs/technical-handoff-C.md).

## Обновление

Перед обновлением сохраните `.env` и каталог данных (`PP_DATA_DIR`, по
умолчанию `~/.promptpilot`). При замене архива сохраните свой настроенный
`.env`, а не заменяйте его шаблоном. Обновляйте worker между задачами;
активные передачи и журналы публикации сначала завершите или переведите
на инженерный разбор. Не удаляйте их как временный кэш.

Релиз не устанавливает индивидуальные операторские профили, ключи и настройки
бота и не включает экспериментальные конвейеры автоматически.

## Установка

- **Windows:** распакуйте `PromptPilot-v0.6.0-windows.zip`, настройте `.env`,
  запустите `start.ps1` или `pp.exe server`. Для бота используйте `start.ps1 -Bot`.
- **Linux без Python:** распакуйте `PromptPilot-v0.6.0-linux.tar.gz`, настройте
  `.env` и выполните `./pp server`.
- **Python / macOS:** установите скачанный wheel в отдельное виртуальное
  окружение: `python -m pip install promptpilot-0.6.0-py3-none-any.whl`,
  затем `pp server`. Готового отдельного macOS-бинаря в этом релизе нет.
- **Из исходников:** `python -m pip install git+https://github.com/ivanarama/PromptPilot.git@v0.6.0`.

Web UI по умолчанию: `http://localhost:8420`. Для исполнения очереди нужен
также `pp worker`; сервер сам по себе задачи не выполняет.

В `SHA256SUMS` опубликованы контрольные суммы Windows-архива, Linux-архива,
wheel и исходного Python-дистрибутива. Сборка проверяет совпадение версии
тега, Python-пакета и runtime, а также идентичность готовых бинарей.
