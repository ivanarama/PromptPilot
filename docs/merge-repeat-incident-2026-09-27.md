Исправление: два подряд явных human-handoff для одного однозначного #N
приостанавливают настроенную pipeline-серию независимо от формулировки.
Отказы UNABLE, разные номера и неоднозначные multi-target причины сохраняют
старое текстовое сравнение. Resume остаётся явным действием оператора.
Регрессионный тест воспроизводит итоговые строки задач #2096 и #2098 через
штатный цикл completion → worker recurrence, без живого GitHub.
